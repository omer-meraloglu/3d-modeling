Build locally: Install requirements.txt in a Python environment, then run python build_all.py --previews. Run each standalone model.py from its own folder to export ./output_model.stl. Expand each product’s printing notes above for orientation, hardware and customization.

Previews are rendered from actual CAD geometry. Colors illustrate optional painting; print files contain single-material models. Default geometry has passed digital checks. Physical printing, hardware fits and application-specific tests remain pending.

All geometry uses millimeters. Each design includes a standalone Python generator. Generated CAD exports remain local and are excluded from Git clones; regenerate them using the root guide.
